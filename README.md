# Landing Page Kedai Kopi — "Kopi Senja"

**Demo live:** [landing-page-kedai-kopi di GitHub Pages](https://kirax-12.github.io/landing-page-kedai-kopi/)

Contoh landing page untuk UMKM kedai kopi, dibuat oleh [Remike Dev](https://github.com/kirax-12) sebagai proyek portofolio. Nama kedai, alamat, dan nomor WhatsApp di dalamnya adalah contoh dan bisa diganti sesuai kebutuhan.

## Fitur

- Hero dengan highlight produk dan statistik kedai
- Menu interaktif: 6 item dengan harga Rupiah, tombol "+ Keranjang"
- Keranjang belanja: ubah jumlah, total otomatis, panel melayang
- Tombol "Pesan via WhatsApp" yang menyusun pesan pesanan otomatis (wa.me)
- Bagian cerita kedai, alamat, jam buka, dan kontak
- Responsif untuk HP dan desktop

## Cara menjalankan

Buka `index.html` langsung di browser, atau:

```bash
npx serve .
```

Untuk memakai nomor WhatsApp asli, ubah konstanta `SHOP_WHATSAPP` di `script.js`.

## Teknologi

HTML · CSS · JavaScript murni, tanpa framework dan tanpa build step.
